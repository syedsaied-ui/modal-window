# Modal Window Project

A simple implementation of modal (popup) windows using JavaScript.

## 🚀 Features
1. Open/close modal
2. Overlay effect
3. Keyboard support (Esc key)

## 💻 Technologies Used
1. HTML
2. CSS
3. JavaScript

## ▶️ How to Run

1. Open the project folder
2. Double click "index.html"

OR (recommended):
Use VS Code Live Server
