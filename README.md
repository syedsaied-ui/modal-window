# Modal Window Project

A simple implementation of modal (popup) windows using JavaScript.

## 🚀 Features
1. Open/close modal
2. Overlay effect
3. Keyboard support (Esc key)

## 💻 Technologies Used
1. HTML
2. CSS
3. JavaScript

## ▶️ How to Run

1. Clone the repository  
2. Open the project folder  
3. Open "index.html" in your browser  

OR use VS Code Live Server
